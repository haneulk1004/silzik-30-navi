# 실직 30일 내비

고용24 AI 고용매니저. 퇴사 후 30일 이내 구직자가 받을 수 있는 고용지원제도를 판정하고, 신청 순서와 기한을 정리해 신청 준비까지 안내하는 서비스입니다.

2026 고용24 국민참여 AI 고용서비스 발굴 온라인 해커톤(고용노동부, 한국고용정보원) 출품작의 개발 저장소입니다.

## 상태

기획 단계입니다. MVP는 해커톤 일정에 맞춰 개발할 예정이며, 이 저장소에 순차적으로 공개합니다.

## 설계 원칙

- 대상 여부 판정은 규칙 엔진이 합니다. 생성형 AI는 조건 추출, 설명, 계획 작성만 맡습니다.
- 정보가 부족하면 "불일치"가 아니라 "확인 필요"로 둡니다.
- 합성 페르소나 30명 기준 정답표로 판정 정확도를 검증합니다.

## 사용 데이터

- 행정안전부_대한민국 공공서비스(혜택) 정보 (공공데이터포털)
- 한국고용정보원_직업훈련_국민내일배움카드 훈련과정 (고용24 OpenAPI)
- 한국고용정보원 공통코드 (고용24 OpenAPI)
- 고용24 제도안내, 찾기쉬운 생활법령정보 (공개 제도 규정)
- 자체 생성한 합성 데이터

실제 개인정보와 고용24 내부 데이터는 사용하지 않습니다. 모든 공공데이터는 화면과 산출물에 출처를 표시합니다.
